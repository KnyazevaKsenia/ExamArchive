# ExamArchive

**ExamArchive** — веб-приложение для хранения учебных материалов и подготовки студентов к экзаменам.

Платформа позволяет искать и просматривать учебные материалы, загружать собственные файлы, добавлять материалы в избранное, работать с личным кабинетом и использовать режим имитации экзамена с наборами билетов.

В проекте также подготовлен интерфейс AI-ассистента. На текущем этапе это UI-заглушка: подключение RAG/backend для ответов по материалам архива ещё не реализовано.

## Возможности

- регистрация и авторизация пользователей;
- JWT-аутентификация с refresh token;
- просмотр архива учебных материалов;
- фильтрация материалов по:
  - курсу;
  - предмету;
  - преподавателю;
  - семестру;
- поиск материалов по ключевому слову;
- просмотр подробной информации о материале;
- загрузка собственных материалов и файлов;
- редактирование и удаление добавленных материалов;
- добавление материалов в избранное;
- личный кабинет пользователя;
- создание наборов экзаменационных билетов;
- просмотр и удаление созданных наборов билетов;
- режим имитации экзамена;
- хранение файлов через MinIO;
- интерфейс AI-ассистента для будущей интеграции с RAG.

## Backend

Backend реализован на **ASP.NET Core / .NET 8**.

Основные части:

- Minimal API endpoints;
- сервисный слой;
- репозитории;
- Entity Framework Core;
- PostgreSQL;
- MinIO;
- JWT-аутентификация;
- AutoMapper;
- FluentValidation.

Основные группы API:

```text
/auth
/materials
/adding
/profile
/examImitation
/favorite
```

### Авторизация

Поддерживаются:

- регистрация;
- вход;
- access token;
- refresh token;
- выход из аккаунта.

Access token передаётся в формате JWT, а refresh token сохраняется в HttpOnly cookie.

### Работа с материалами

Пользователь может:

- получать список материалов;
- применять фильтры;
- искать материалы по ключевым словам;
- открывать карточку отдельного материала;
- скачивать связанные файлы;
- добавлять новый материал;
- редактировать и удалять собственные материалы.

Метаданные материалов хранятся в PostgreSQL, а файлы — в MinIO.

### Избранное

Авторизованные пользователи могут сохранять нужные материалы в избранное для быстрого доступа.

### Имитация экзамена

Система позволяет создавать и хранить наборы экзаменационных билетов.

Для авторизованного пользователя доступны:

- создание набора билетов;
- получение списка наборов;
- просмотр отдельного набора;
- удаление набора;
- работа с интерфейсом имитации экзамена.

## Frontend

Frontend реализован на **Vue 2** и собирается через **Vite**.

Основные страницы:

```text
/                 — главная страница
/materials        — архив материалов
/materials/:id    — страница материала
/adding           — добавление материала
/mypage           — личный кабинет
/exam             — имитация экзамена
/favorite         — избранные материалы
/assistant        — AI-ассистент
```

Для запросов к backend используется **Axios**, навигация реализована через **Vue Router**.

Часть страниц доступна только авторизованным пользователям.

## AI-ассистент

В проекте есть отдельная страница AI-ассистента.

Сейчас она работает как демонстрационный интерфейс и возвращает тестовый ответ.

Планируемая логика:

```text
Вопрос пользователя
        ↓
Поиск релевантных материалов архива
        ↓
RAG / backend
        ↓
Ответ по учебным материалам
        ↓
Ссылки на источники
```

На текущем этапе RAG и backend для AI-ассистента не подключены.

## Схема работы

```text
Vue frontend
     ↓
ASP.NET Core API
     ↓
┌───────────────┬───────────────┐
│  PostgreSQL   │     MinIO     │
│   metadata    │     files     │
└───────────────┴───────────────┘
```

Пример сценария работы с материалом:

```text
Пользователь открывает архив
        ↓
Выбирает фильтры или поиск
        ↓
Frontend отправляет запрос к API
        ↓
Backend получает данные из PostgreSQL
        ↓
Для материала запрашиваются файлы из MinIO
        ↓
Пользователь получает карточку материала
```
